What is HTML?

HTML (HyperText Markup Language) isn’t actually a “coding” or programming language—it’s a markup language used to structure content on the web.

Think of it like the skeleton of a webpage:

  • It tells the browser what things are (headings, paragraphs, images, links, etc.)
  • It doesn’t perform logic like programming languages (such as JavaScript or Python)

Basic idea

HTML uses tags to wrap content:

<h1>This is a heading</h1>
<p>This is a paragraph</p>
<a href="https://example.com">This is a link</a>

What HTML does

  • Organizes text (headings, paragraphs, lists)
  • Embeds images and videos
  • Creates links between pages
  • Builds the basic structure of websites

What HTML does NOT do

  • It doesn’t handle complex logic or calculations
  • It doesn’t make pages interactive on its own

Other technologies used with HTML

  • CSS – for styling (colors, layout)
  • JavaScript – for interactivity (buttons, animations, logic)

Basic Structure

<!DOCTYPE html>
<html>
<head>
    <title>Page Title</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>This is a paragraph.</p>
</body>
</html>

1. DOCTYPE

<!DOCTYPE html> tells the browser this is an HTML5 document. It should always be the first line.

2. HTML Element

<html> is the root element. Everything on the page goes inside it.

3. Head Section

<head> contains information about the page (not visible to users).

  • <title> – shown in the browser tab
  • Metadata
  • Links to CSS or scripts

4. Body Section

<body> contains all visible content.

  • Headings (<h1> to <h6>)
  • Paragraphs (<p>)
  • Links (<a>)
  • Images (<img>)
  • Lists (<ul>, <ol>, <li>)

Nesting Elements

HTML elements can go inside each other (this is called nesting):

<body>
    <div>
        <p>This is inside a div</p>
    </div>
</body>

Quick Summary

  • DOCTYPE → tells browser the type
  • html → entire page
  • head → settings
  • body → visible content

Common Tags

Common HTML Tags

These are some of the most commonly used HTML tags and what they do.

Headings

Used for titles and section headings:

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>

Paragraph

Used for blocks of text:

<p>This is a paragraph.</p>

Links

Used to create clickable links:

<a href="https://example.com">Visit Website</a>

Images

Used to display images:

<img src="image.jpg" alt="Description">

Lists

Unordered (bullets):

<ul>
    <li>Item 1</li>
    <li>Item 2</li>
</ul>

Ordered (numbered):

<ol>
    <li>First</li>
    <li>Second</li>
</ol>

Div (Container)

Used to group elements together:

<div>
    <p>Content inside a div</p>
</div>

Span (Inline Container)

Used to style or group small parts of text:

<span>Inline text</span>

Line Break

Creates a new line:

Line one<br>Line two

Horizontal Line

Creates a divider line:

<hr>

Buttons

Creates a clickable button:

<button>Click Me</button>

Quick Summary

  • Headings: h1–h6
  • Text: p
  • Links: a
  • Images: img
  • Lists: ul, ol, li
  • Containers: div, span
  • Extras: br, hr, button
